# Power Turborepo

Ce dépôt contient une configuration Turborepo vide initialisée avec pnpm. Il fournit la structure de base (`apps/` et `packages/`) et des scripts npm pour piloter Turbo.

## Pour démarrer

```sh
pnpm install
pnpm dev
```

Ajoutez vos applications dans `apps/` et vos packages partagés dans `packages/`.
